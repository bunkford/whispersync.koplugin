# bunkford's KOReader plugins

Two KOReader plugins for Kindle readers, published from one repository so a
single ZenPM source serves both.

**Kindle Whispersync** (`whispersync.koplugin/`) reads your **Send-to-Kindle
library straight from Amazon** and keeps **reading position, bookmarks,
highlights and notes** in sync with your Kindle account, speaking the device
protocol Kindle hardware speaks. No stock-reader middleman, no KRDS sidecar
files. Full documentation: [`whispersync.koplugin/README.md`](whispersync.koplugin/README.md).

**Read Aloud (Edge voices)** (`readaloud.koplugin/`) reads the open book with
**Microsoft Edge's neural voices**, synthesized on the device over Wi-Fi, and
**marks each word on the page as it is spoken**, with Bluetooth audio on
Kindle. Works with any EPUB/MOBI KOReader opens, no server needed. Full
documentation: [`readaloud.koplugin/README.md`](readaloud.koplugin/README.md).

## Install with ZenPM

In ZenPM, **Sources → Add**:

```
https://bunkford.github.io/whispersync.koplugin/
```

then install **Kindle Whispersync** and/or **Read Aloud (Edge voices)**.
Updates arrive through ZenPM's normal update checks whenever a new release is
published here.

## Install by hand

Download `whispersync.koplugin.zip` or `readaloud.koplugin.zip` from the
[releases](https://github.com/bunkford/whispersync.koplugin/releases), extract
it into `koreader/plugins/` on the device, and restart KOReader.

## Repository layout

```

readaloud.koplugin/     Read Aloud (Edge voices) (desktop tests under tests/)
tools/                  release tooling: build_plugin.sh <plugin>, release.sh <plugin>,
                        zenpm_manifest.py --plugin <plugin>, and export_device.py to reuse
                        the Kindle dashboard's Amazon registration
zenpm/                  the static ZenPM repository (both packages), regenerated by the release workflow
.github/workflows/      release.yml: tests, archive, GitHub release, manifest update, Pages
```
