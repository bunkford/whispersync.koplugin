# Kindle Whispersync for KOReader

A KOReader plugin that reads your **Send-to-Kindle library straight from
Amazon** and keeps **reading position, bookmarks, highlights and notes** in sync
with your Kindle account, speaking the device protocol Kindle hardware speaks.
No stock-reader middleman, no KRDS sidecar files.

The plugin itself, with its full documentation, is in
[`whispersync.koplugin/`](whispersync.koplugin/README.md).

## Install with ZenPM

In ZenPM, **Sources → Add**:

```
https://raw.githubusercontent.com/bunkford/whispersync.koplugin/main/zenpm/
```

then install **Kindle Whispersync**. Updates arrive through ZenPM's normal
update checks whenever a new release is published here.

## Install by hand

Download `whispersync.koplugin.zip` from the
[latest release](https://github.com/bunkford/whispersync.koplugin/releases/latest),
extract it into `koreader/plugins/` on the device, and restart KOReader.

## Repository layout

```
whispersync.koplugin/   the plugin (and its desktop tests under tests/)
tools/                  release tooling: build_plugin.sh, release.sh, zenpm_manifest.py,
                        and export_device.py to reuse the Kindle dashboard's registration
zenpm/                  the static ZenPM repository, regenerated by the release workflow
.github/workflows/      release.yml: tests, archive, GitHub release, manifest update
```
